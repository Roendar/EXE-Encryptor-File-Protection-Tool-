# 🔐 EXE Encryptor

Welcome to the EXE Encryptor!

A simple tool for protecting executable files through encryption and customizable security settings.

## 🚀 How to Use

1. **Launch** – Open the encryptor.
2. **Select EXE** – Choose the executable you want to protect.
3. **Configure Options** – Adjust the available encryption settings.
4. **Set Output** – Choose where to save the encrypted file.
5. **Encrypt** – Start the encryption process.
6. **Verify** – Test that your file can be safely recovered and executed.
6. **Verify** – It can bypass virussoftwares and windows defender.
